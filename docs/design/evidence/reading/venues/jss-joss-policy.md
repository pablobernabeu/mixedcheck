# JSS: software already published in JOSS

**Pages read.** Journal of Statistical Software, 'Information on Mission' (https://www.jstatsoft.org/mission), 'Information for Authors' (https://www.jstatsoft.org/authors) and 'Submissions' (https://www.jstatsoft.org/about/submissions), read 21 November 2026, searched for JOSS, earlier publication and other journals.

**Fact.** None of these pages states a policy on software that has already been described in the Journal of Open Source Software. The nearest rule concerns methods: novel models or estimation procedures should be published elsewhere first, and a later JSS article on a corresponding package requires a substantial software innovation (Mission, Types of Papers). Manuscripts rejected by JSS cannot be resubmitted (Information for Authors).

**For the record.** open_items_local_session.csv flags a risk of double publication if both JOSS and JSS are used. 02-decisions.md (Q9) already treats JSS as an alternative that would replace JOSS, not an addition, which avoids the question; the public pages do not settle whether JSS would consider software that JOSS has published.
