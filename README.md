# lmecheck

A planned pair of packages, one for R and one for Python, for auditing designs before fitting linear mixed-effects models and for diagnosing and reporting fitted models, with the same checks and outputs in both languages. The repository currently holds the design.

- [Design review](docs/design/01-design-review.md): critical review of the architecture, edge cases and additional features
- [Decision record](docs/design/02-decisions.md): resolved design questions, with evidence and the choices left to the maintainer
- [Execution plan](docs/design/03-execution-plan.md): milestones and gates, validation on the HPC, risks and open checks
- [Evidence](docs/design/evidence/): review catalogue, benchmark, simulations, schemas and prototypes behind the decisions
