# Psychological Methods: time to first decision, TOP level and code requirements

**Pages read.** American Psychological Association, 'Psychological Methods' (https://www.apa.org/pubs/journals/met) and 'Psychological Methods Submission Guidelines' (https://www.apa.org/pubs/journals/met/submit); 'Journal Statistics and Operations Data' (https://www.apa.org/pubs/journals/statistics); the Center for Open Science's TOP Guidelines page, to which topfactor.org now redirects (https://www.cos.io/initiatives/top-guidelines). All read 21 November 2026; the APA cookie banner was answered with 'Reject All'.

**Fact.**
- Time to first decision: APA publishes its journal operations data as annual reports, the latest listed being for 2023: American Psychological Association. (2024). Summary report of journal operations, 2023. *American Psychologist, 79*(5), 777–778. https://doi.org/10.1037/amp0001383 (PDF at https://www.apa.org/pubs/journals/features/2023-statistics.pdf; Crossref agrees on journal, volume, issue, pages and DOI). The server refuses automated requests, so the maintainer saved the PDF and it was read on 22 November 2026. The report gives no time to first decision. For Psychological Methods in 2023 it gives 321 manuscripts received, 77 accepted and 119 pending, a rejection rate of 66% (74% counting out-of-scope submissions), 80 items and 1,490 pages published, and an average lag from acceptance to publication of 3.7 months online first and 15.2 months in print (p. 777).
- TOP level: the submission guidelines do not state a TOP level. They say that open-science practices vary across subfields and are at the editor's discretion, and refer authors to each journal's guidance. The TOP Factor database, which rated journals against the TOP guidelines, now redirects to the page for TOP 2025, which does not list journal ratings.
- Code: runnable source code should be supplied as supplemental material; code shown in the article is set from a separate file (Computer code). Articles can earn open-science badges for open data, open materials and preregistration, on self-disclosure with a signed form, with the items in an open repository with a persistent identifier (Open science badges). Submitting a manuscript is free of charge (Open access).

**For the record.** open_items_local_session.csv asks for the time to first decision and the TOP level and code requirements. The code requirement is settled. The registered-report special issue (see rr-psychological-methods.md) promises first decisions by the end of May 2027 for Stage 1 reports due on 1 April 2027, which answers the timing question for that route.
